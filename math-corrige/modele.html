Corrigé : Question 3

Un système de 3 équations à 4 inconnues, expliqué pas à pas.

L'énoncé Consider the following system :  
x₁ − x₂ = 1x₂ − x₃ = 1x₃ + 3x₄ = 3
1) Write this system in matrix form.
2) Show that this system of equations has infinite solutions.
3) Provide one unique solution associated to x₄ = −1.
4) Provide one unique solution associated to x₄ = 1.

Ce que l'énoncé veut dire, en français simple

QuestionEn vrai, on te demande…Outil
1de ranger les nombres du système dans des tableauxA · x = b
2de prouver qu'il existe une infinité de 4-uplets qui marchentescalier, pivots, variable libre
3de trouver LA solution quand on impose x₄ = −1remplacer, remonter
4pareil avec x₄ = 1remplacer, remonter
✎ L'idée en une phrase On a 4 inconnues mais seulement 3 équations (3 « règles »). Les règles ne suffisent pas à bloquer les 4 nombres : il en reste un qu'on peut choisir librement (ici x₄). Une fois qu'on l'a choisi, les 3 autres sont forcés. Les questions 3 et 4, c'est justement « choisis x₄, et trouve les autres ».

Le vocabulaire à connaître

SolutionUne liste de 4 nombres (x₁, x₂, x₃, x₄) qui rend les 3 équations vraies en même temps.
CoefficientLe nombre devant une inconnue. Dans « 3x₄ », c'est 3. Dans « −x₂ », c'est −1. Si l'inconnue n'apparaît pas, c'est 0.
PivotLe premier nombre non nul d'une ligne, une fois le système en escalier.
Variable libreUne inconnue sans pivot : on lui donne la valeur qu'on veut (on l'appelle t).

1) La forme matricielle

📗 Rappel du cours : écrire un système en A · x = b Tout système linéaire peut s'écrire avec 3 « tableaux » :
• A, la matrice des coefficients : une ligne par équation, une colonne par inconnue ;
• x, le vecteur des inconnues, écrit en colonne ;
• b, le second membre : ce qu'il y a à droite du « = », en colonne.
Cours chap. 1, « Systems of linear equations ».
1On fait la liste des inconnues, dans l'ordre : x₁, x₂, x₃, x₄. Il y en a 4, donc A aura 4 colonnes. Il y a 3 équations, donc A aura 3 lignes.
2On réécrit chaque équation avec les 4 inconnues dans l'ordre. Celles qui manquent ont un coefficient 0, et un « x » tout seul a un coefficient 1 :
Équationx₁x₂x₃x₄= b
x₁ − x₂ = 11−1001
x₂ − x₃ = 101−101
x₃ + 3x₄ = 300133
3On recopie ce tableau : les 4 colonnes « x » donnent A, la colonne « = b » donne b :
1−10001−100013 · x₁x₂x₃x₄ = 113

soit A · x = b, avec A de taille 3 × 4, x de taille 4 × 1, b de taille 3 × 1.

4On vérifie en refaisant le produit A · x (ligne de A × colonne x, comme à l'exo 1 du devoir) :
ligne 1 : 1·x₁ + (−1)·x₂ + 0·x₃ + 0·x₄ = x₁ − x₂  → doit valoir 1 ✓ (équation 1)
ligne 2 : 0·x₁ + 1·x₂ + (−1)·x₃ + 0·x₄ = x₂ − x₃  → doit valoir 1 ✓ (équation 2)
ligne 3 : 0·x₁ + 0·x₂ + 1·x₃ + 3·x₄ = x₃ + 3x₄  → doit valoir 3 ✓ (équation 3)

On retombe sur le système de départ ✓. Les 0 en vert du tableau = les inconnues absentes.

⚠ Les pièges · Oublier les 0 : chaque ligne de A doit avoir 4 cases, même si l'équation n'a que 2 inconnues.
· Le signe : « x₁ − x₂ », c'est 1·x₁ + (−1)·x₂. On écrit −1 dans A, pas 1.
· Les tailles : (3 × 4) · (4 × 1) = (3 × 1), la taille de b ✓.

2) Montrer qu'il y a une infinité de solutions

📗 Rappel du cours : combien de solutions ? Un système linéaire a toujours 0, 1 ou une infinité de solutions, jamais 2 ou 3. Pour savoir lequel, on le met en escalier (pivot de Gauss), puis :
• une ligne « 0 = un nombre non nul » → aucune solution ;
• sinon, autant de pivots que d'inconnues → une seule solution ;
• sinon, moins de pivots que d'inconnues → une infinité (les inconnues sans pivot sont libres).
Cours chap. 1, pivot de Gauss. C'est le même raisonnement que l'exo 7 du devoir.
1On écrit la matrice augmentée [A | b] : c'est A, plus la colonne b collée à droite derrière une barre.
1−1001 01−101 00133  ← déjà en escalier !
2Pourquoi « en escalier » ? Regarde où commence chaque ligne :
ligne 1 : premier nombre non nul en colonne 1
ligne 2 : premier nombre non nul en colonne 2  ← une marche plus à droite
ligne 3 : premier nombre non nul en colonne 3  ← encore une marche

Chaque ligne commence plus à droite que celle du dessus, avec des 0 en bas à gauche. C'est exactement ce que le pivot de Gauss chercherait à obtenir. Ici, il n'y a aucune opération à faire. Les pivots sont les 3 nombres surlignés en jaune.

3Test n°1 : y a-t-il une contradiction ? On cherche une ligne de la forme (0 0 0 0 | c) avec c ≠ 0, qui voudrait dire « 0 = c », impossible.

Chaque ligne a un pivot non nul à gauche de la barre → aucune ligne de ce type. ✓ Le système a au moins une solution.

4Test n°2 : y a-t-il une inconnue libre ? On compte :
Colonnex₁x₂x₃x₄
A un pivot ?ouiouiouinon

3 pivots pour 4 inconnues : il reste 4 − 3 = 1 inconnue libre, c'est x₄.

Conclusion du cours Pas de contradiction + une inconnue libre ⟹ une infinité de solutions.
Version « rang » Le rang = le nombre de pivots. rang(A) = rang([A|b]) = 3, et 3 < 4 inconnues ⟹ infinité de solutions.

On le prouve concrètement : toutes les solutions

1On pose x₄ = t, où t est n'importe quel nombre réel. ← t, c'est un curseur qu'on peut bouger
2On remonte l'escalier : on part de la dernière équation (une seule inconnue en plus de t), puis on remonte.
Équation 3 : x₃ + 3x₄ = 3
  on remplace x₄ par t : x₃ + 3t = 3
  on passe 3t de l'autre côté (il change de signe) : x₃ = 3 − 3t
Équation 2 : x₂ − x₃ = 1  donc  x₂ = 1 + x₃
  on remplace x₃ par ce qu'on vient de trouver : x₂ = 1 + (3 − 3t)
  on additionne : x₂ = 4 − 3t
Équation 1 : x₁ − x₂ = 1  donc  x₁ = 1 + x₂
  on remplace x₂ : x₁ = 1 + (4 − 3t)
  on additionne : x₁ = 5 − 3t
3On rassemble :
(x₁, x₂, x₃, x₄) = (5 − 3t, 4 − 3t, 3 − 3t, t), pour tout réel t
4On vérifie la formule en la remettant dans les 3 équations, avec t quelconque :
x₁ − x₂ = (5 − 3t) − (4 − 3t) = 5 − 3t − 4 + 3t = 1 ✓  ← les t s'annulent
x₂ − x₃ = (4 − 3t) − (3 − 3t) = 4 − 3t − 3 + 3t = 1 ✓
x₃ + 3x₄ = (3 − 3t) + 3t = 3 ✓  ← vrai quel que soit t
5Quelques exemples, pour voir que ça marche vraiment :
t(x₁, x₂, x₃, x₄)x₁ − x₂x₂ − x₃x₃ + 3x₄
0(5, 4, 3, 0)1 ✓1 ✓3 ✓
2(−1, −2, −3, 2)1 ✓1 ✓−3 + 6 = 3 ✓

Chaque valeur de t donne une solution différente (x₄ change), et il y a une infinité de nombres réels t. Donc le système a une infinité de solutions. ✓ C.Q.F.D.

⚠ Les pièges · « 3 équations, 4 inconnues » ne suffit pas : x₁ + x₂ = 1 et x₁ + x₂ = 2 est impossible. Il faut aussi « pas de contradiction ».
· Un « − » devant une parenthèse change tous les signes : −(4 − 3t) = −4 + 3t.

3) La solution pour x₄ = −1

Le mot « unique » : une fois x₄ fixé, il n'y a plus d'inconnue libre. x₃, x₂, x₁ sont forcés l'un après l'autre, il n'y a qu'une seule possibilité.

Méthode A : on remonte l'escalier directement.

1Équation 3 avec x₄ = −1 : x₃ + 3×(−1) = 3, donc x₃ − 3 = 3, donc x₃ = 6. ← 3 × (−1) = −3
2Équation 2 : x₂ − x₃ = 1, donc x₂ = 1 + x₃ = 1 + 6, donc x₂ = 7.
3Équation 1 : x₁ − x₂ = 1, donc x₁ = 1 + x₂ = 1 + 7, donc x₁ = 8.

Méthode B : on utilise la formule de la question 2 avec t = −1.

x₁ = 5 − 3×(−1) = 5 + 3 = 8    x₂ = 4 − 3×(−1) = 7    x₃ = 3 − 3×(−1) = 6  ← même résultat ✓
Pour x₄ = −1 : (x₁, x₂, x₃, x₄) = (8, 7, 6, −1)
✓Vérif dans l'énoncé : 8 − 7 = 1 ✓   7 − 6 = 1 ✓   6 + 3×(−1) = 6 − 3 = 3 ✓

4) La solution pour x₄ = 1

1Équation 3 avec x₄ = 1 : x₃ + 3×1 = 3, donc x₃ + 3 = 3, donc x₃ = 0.
2Équation 2 : x₂ = 1 + x₃ = 1 + 0, donc x₂ = 1.
3Équation 1 : x₁ = 1 + x₂ = 1 + 1, donc x₁ = 2.
Avec la formule, t = 1 : x₁ = 5 − 3 = 2, x₂ = 4 − 3 = 1, x₃ = 3 − 3 = 0  ← pareil ✓
Pour x₄ = 1 : (x₁, x₂, x₃, x₄) = (2, 1, 0, 1)
✓Vérif : 2 − 1 = 1 ✓   1 − 0 = 1 ✓   0 + 3×1 = 3 ✓
⚠ Les pièges · Commencer par l'équation 1 : elle a 2 inconnues qu'on ne connaît pas encore (x₁ et x₂), on est bloqué. Toujours partir du bas de l'escalier.
· x₃ = 0 n'est pas une erreur : 0 est un résultat tout à fait normal.
· Les deux solutions sont « décalées » de 6 sur x₁, x₂, x₃ : quand x₄ augmente de 2, les autres baissent de 3 × 2 = 6. Ça colle avec le « −3t » ✓.

À retenir

🎤 À l'oral, dis : « Pour la forme matricielle, je range les coefficients dans A, une ligne par équation et une colonne par inconnue, en mettant 0 pour les inconnues absentes. A est de taille 3 × 4, x est le vecteur des 4 inconnues et b vaut (1, 1, 3).
Pour montrer l'infinité de solutions, j'écris la matrice augmentée : elle est déjà en escalier. Il y a 3 pivots, aucune ligne du type 0 = c, donc le système est compatible. Comme il y a 4 inconnues pour 3 pivots, x₄ est libre.
Je pose x₄ = t et je remonte : x₃ = 3 − 3t, x₂ = 4 − 3t, x₁ = 5 − 3t. Chaque réel t donne une solution, donc il y en a une infinité.
Enfin, pour x₄ = −1 je trouve (8, 7, 6, −1), et pour x₄ = 1 je trouve (2, 1, 0, 1). J'ai vérifié les deux dans les trois équations. »
